# YADRO-Импульс

Angular-приложение, которое взаимодействует с внешними API и управляет данными пользователей.

## Разработка
Чтобы запустить локально приложение, требуется:
1. Склонировать репозиторий и перейти в папку проекта
```bash
git clone https://github.com/DashaSmir/yadro2.git
cd yadro2

```

2. Установить необходимые зависимости
```bash
npm install
```

```bash
ng serve
```

Когда он запустится, необходимо перейти на `http://localhost:4200/`
